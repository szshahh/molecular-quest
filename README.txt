MOLECULAR QUEST — CENTRAL DOGMA
Prototype 0.1

A biochemical 2.5D-inspired browser platformer concept.
Current build establishes the 5-season / 50-level progression and begins Season 1 with nucleotide collection.

Season roadmap:
1. DNA / Nucleus
2. RNA / Transcriptome
3. Translation / Ribosome
4. Protein Folding / ER
5. Molecular Machines

Planned first real protein target: human ubiquitin, PDB 1UBQ (76 residues).

Controls:
A/D or arrow keys: move
Space/W/Up: jump
Shift/X: dash
Touch controls appear on mobile.

Open index.html in a browser.
